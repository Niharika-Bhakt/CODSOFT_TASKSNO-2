# QuizVerse 🎯

### Test Your Knowledge. Create. Play. Learn.

QuizVerse is an interactive quiz platform designed to make learning and testing knowledge simple, engaging, and fun. Users can explore quizzes across different categories, attempt multiple-choice questions, track their scores, and create their own quizzes.

---

## ✨ Features

- 📚 Explore quizzes across multiple categories
- 🧠 10-question multiple-choice quizzes
- 📊 Real-time score and progress tracking
- 🔄 Retry quizzes and improve your score
- ✏️ Create your own custom quizzes
- 🎯 Choose quiz category and difficulty
- 👀 Live quiz preview while creating
- 🚀 Publish quizzes directly from the creator page
- 🔐 User Login and Sign Up
- 💾 Store created quizzes in MongoDB Atlas

## 🎮 How It Works

1. Choose a quiz category.
2. Start the quiz and answer the questions.
3. Track your progress as you play.
4. Get your final score after completing the quiz.
5. Retry the quiz to improve your performance.
6. Create and publish your own quizzes using the Quiz Creator.
